Protocol and interpretation

This measures coverage of the evaluated reference library. It establishes held-out generalization only when that library is a separately identified evaluation split. The task’s native failures and completion horizon remain authoritative.

Root-relative error subtracts each trajectory’s own root position; no rotation or Procrustes alignment is applied. Matched points are not assumed to be anatomical joints. Velocity error compares the reference derivatives with live point/body velocity. Errors over completed trials can favor easier trajectories; observed-prefix errors can favor early failures. Inspect both alongside completion and progress.

Confidence intervals, when shown, are 95% Wilson intervals per motion under randomized trials. They are omitted for nominal or incomplete/invalid coverage. Motion-level intervals do not describe uncertainty across a different motion population. Changing concurrency changes batch RNG draws.
