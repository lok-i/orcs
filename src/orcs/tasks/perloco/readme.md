# PerLoco

PerLoco provides privileged terrain-aware locomotion over staged terrain-motion
pairs. Runtime code consumes only the ORCS-native layout and the packaged roster
keeps terrain tiles paired with their valid clips.

User workflows live in:

- [Perceptive locomotion setup](../../../../docs/perceptive_locomotion.md)
- [SMPL retargeting and training](../../../../docs/smpl_retargeting.md)

Architecture and package boundaries are documented in
[the ORCS ethos](../../../../docs/ethos.md).
